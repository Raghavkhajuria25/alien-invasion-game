# 👾 Alien Invasion Game

A Python-based 2D Alien Invasion game built with Pygame.

## 📌 About

Alien Invasion is a simple arcade-style game where the player controls a spaceship, shoots incoming aliens, and tries to survive as long as possible.

This project was built to practice Python programming, game development concepts, object-oriented programming, and event-driven programming.

## 🚀 Features

- 🚀 Player spaceship movement
- 👾 Multiple alien enemies
- 🔫 Shooting system
- 💥 Bullet and alien collision detection
- 🎮 Keyboard controls
- ❤️ Game Over system
- ⚡ Increasing game difficulty
- 🖥️ Pygame-based graphical interface

## 🛠️ Technologies Used

- Python
- Pygame
